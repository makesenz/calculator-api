# Calculator API

A simple REST API for basic mathematical operations built with **FastAPI** and Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero validation
- Automatic input validation
- Interactive API documentation with Swagger UI
- API documentation with ReDoc

## Tech Stack

- Python
- FastAPI
- Uvicorn
- REST API
- Git & GitHub
